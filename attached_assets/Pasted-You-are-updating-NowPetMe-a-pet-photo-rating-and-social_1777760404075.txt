### 1. BAYESIAN WEIGHTED LEADERBOARD SCORING

Replace the current average-rating sort with a Bayesian weighted score so that pets with more votes rank more reliably than pets with very few votes.

Formula:
  bayesian_score = (v / (v + m)) * R + (m / (v + m)) * C

Where:
  v = number of votes for this pet
  R = average rating for this pet
  m = minimum votes threshold (use 10 as the constant)
  C = global average rating across ALL pets

Implementation:
- Add a computed `bayesian_score` column to the pets table (or calculate it on the fly in queries)
- Recalculate on every new vote
- Use bayesian_score for all leaderboard and category sorting (when sort = "top-rated")
- Keep showing the real average star rating to users (don't display the Bayesian score directly — it's just for ranking)
- Update all existing leaderboard queries, homepage top-rated sections, and category pages to use this new sort
